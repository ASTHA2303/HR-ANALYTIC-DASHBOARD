HR Analytics Dashboard 📊
An interactive HR Analytics Dashboard built in Microsoft Excel to analyze workforce dynamics, track employee turnover, and evaluate key performance and engagement metrics.  
📌 Project Overview
Human Resource analytics plays a crucial role in improving retention rates, optimizing workforce planning, and understanding employee satisfaction. This project transforms raw HR data into an actionable visual dashboard that provides real-time insights into employee demographics, education levels, travel patterns, and attrition rates.  
📊 Key Metrics (KPIs)
Total Employees: 2,925  
Current Active Employees: 2,433  
Exit Employees (Attrition): 492  
Average Work-Life Balance: 2.76 / 4.0  
Average Performance Rating: 3.0 / 4.0 

🔎 Key Insights & Features
1. Workforce Demographics
Gender Distribution: 1,754 Male and 1,171 Female employees.  
Marital Status Breakdown: 1,340 Married, 934 Single, and 651 Divorced staff members.
 
2. Attrition & Engagement Analysis
Attrition by Marital Status: Visualizes turnover counts across married, single, and divorced employees to identify high-risk groups.
 
Job Involvement: Compares job involvement scores across marital groups (Single: 2.69, Married/Divorced: 2.75).  
3. Education & Business Travel Trends
Education by Gender: Tracks qualifications (Bachelor's, Master's, Associate's, High School, Doctoral) split by gender.  
Travel Frequency: Analyzes travel commitments (Non-Travel, Travel Frequently, Travel Rarely) across gender categories.  

4. Interactive Filtering
Dynamic Slicers: Allows filtering of all dashboard metrics by Hiring Year (2020–2023), Gender, and Attrition Status (Yes/No).  
🛠️ Tools & Skills Demonstrated

Tool: Microsoft Excel  
Techniques: Pivot Tables, Pivot Charts, Data Modeling, Dynamic Slicers, Dashboard UI/UX Design  
Analytics Domain: HR Analytics, Workforce Planning, Attrition Analysis, People Analytics
